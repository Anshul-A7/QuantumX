# Agent Scratchpad

**Shared, structured problem-solving log.**

This file bridges `PROBLEM.md` (the owner's plain-language issues) and actual execution. When agents pull issues from `PROBLEM.md`, they bring them here, define them precisely, tag their status, and log the resolution.

**Never delete entries from this file.** Resolved problems are our history of what didn't work and how we fixed it.

## Entry Template
Use the following format for each entry:
```markdown
### [Date] - [Short Title]
- **Source:** (Link or reference to PROBLEM.md entry)
- **Status:** [Open | In Progress | Resolved | Blocked]
- **Agent:** [Your Name/ID]
- **Problem:** [Precise technical definition of the issue]
- **Resolution/Notes:** [If resolved, exactly how. If blocked, what was tried and why it failed. Link to LOGS.md entry if applicable.]
```
